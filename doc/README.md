## 快速定位

- **想知道怎么跑起来** → 04
- **想知道表怎么设计的** → 02
- **要对接接口 / 写前端** → 03
- **想改上传逻辑** → 05
- **要批量导入服务器上的视频** → 10
- **要让插件投递 m3u8 下载任务** → 11
- **想改播放器交互** → 06
- **搞不清用户为什么看不到某个视频** → 07
- **准备二次开发** → 01 + 08

## 相关目录

| 目录 | 说明 |
| --- | --- |
| `backend/` | FastAPI 后端源码 |
| `frontend/` | 前端静态站点（管理端 + 用户端，多页） |
| `config/` | 配置文件与其说明 |
| `sql/` | 数据库脚本（基线 + 增量） |
| `storage/` | 运行时产生的媒体文件、分片、日志（不入库） |
| `tools/` | 外部可执行文件（`N_m3u8DL-RE`、`ffmpeg`），由 `scripts/fetch_tools.py` 拉取，不入库 |
